Integrate TrustIQ

Deploy TrustIQ directly into any website. Use our zero-trust Client-Side plugin to monitor payloads directly in the user's browser, or route traffic through our Gateway Proxy.

Option 1: Universal Client-Side Script

Include this script tag in the <head> of any HTML file. It will automatically intercept fetch requests, forms, and DOM mutations to block tampering (like admin_password="SuperSecret") before it reaches the backend.

<!-- TrustIQ Zero-Trust Edge Security --> <script src="https://cdn.trustiq.com/v2/shield.min.js" data-site-id="TIQ-8899A"></script> <script> TrustIQ.init({ blockTampering: true, blockSQLi: true, dlpProtect: true }); </script>
